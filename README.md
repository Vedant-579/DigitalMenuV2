# Smart Restaurant Management System

A full-stack restaurant management system built using React.js, Node.js, Express.js, and PostgreSQL.

## Features

- Menu CRUD operations
- Category-based filtering
- Menu search
- Shopping cart
- Quantity management
- Cart total calculation
- Customer and table details
- Order placement
- PostgreSQL order persistence
- RESTful APIs
- Backend price validation
- Database transactions

## Tech Stack

- React.js
- Node.js
- Express.js
- PostgreSQL
- JavaScript
- REST APIs
- Postman
